# AGENTS.md

## 役割

楽天EC（楽天市場）店舗のデザイナー向け作業ディレクトリ。
HTML/CSS を用いた楽天店舗ページ（ヘッダー / 左ナビ / フッター等）のパーツ制作と、
月次商品（アイテム）ページの制作・管理を行う。

## ディレクトリ構成

```
aki-work/
├── design/                 デザインパーツ（店舗共通の HTML パーツ）
│   ├── header/             ヘッダーパーツ
│   │   └── header01.html
│   ├── leftnav/            左ナビゲーションパーツ
│   │   └── leftnav01.html
│   ├── footer/             フッターパーツ（注: ファイル名は leftnav01.html のまま）
│   │   └── leftnav01.html
│   └── memo                API キー等のメモファイル（コミット・共有しない）
├── company-site/           会社サイト（静的HTML/CSS/JS・ビルド不要）
├── items/                  商品ページ（月別）
│   ├── 2026-11/
│   └── 2026-12/
├── img/                    画像素材
└── script/                 一時スクリプト置き場（Python / Node.js 等）
```

## 命名規則

- パーツファイルは `<パーツ名><連番2桁>.html`（例: `header01.html`, `leftnav01.html`）
- バリエーション追加は連番を増やす（`header02.html` …）既存ファイルは上書きしない
- 商品ディレクトリは `items/YYYY-MM/` 形式（月単位で管理）

## 作業ルール

- **楽天市場の仕様に準拠**する
  - 楽天の商品ページ / 店舗ページはテーブルレイアウトやインライン CSS が前提の箇所があるため、
    実ページに組み込める形（外部 CSS 依存を最小化）で出力する
  - 楽天側で禁止されているタグ・属性（`<script>`, `position: fixed` の多用, `iframe` 等）を避ける
  - 画像パスは公開後の配置場所（楽天GOLD / RMS の画像サーバ）を考慮し、相対パスで記述してから置換する
- 文字コードは **UTF-8 (BOM なし)**、改行は LF
- 日本語テキストを含むファイルは必ず UTF-8 で保存する
- 既存パーツを修正する場合は、他ページへの影響を考慮し
  新規連番ファイルとして追加することを基本とする
- 画像は `img/` に配置し、ファイル名は半角英数字・ハイフン区切り（例: `header-logo-202611.png`）

## script フォルダ（一時スクリプト）

- `script/` は Python / Node.js などで処理を行うときの**一時スクリプト置き場**
- Excel / CSV / HTML の加工、画像編集などを行うときは、ソースの作成と実行をこの `script/` 配下で行う
- 成果物（Excel / CSV / HTML / 画像等）は `img/` や各パーツ・商品ページへ配置し、`script/` には一時ファイル・中間生成物を残さない
- スクリプトファイル名は半角英数字・ハイフン区切り（例: `convert-csv-202611.py`）
- シークレット（API キー等）を含むスクリプトやログはコミット・共有しない

## 禁止事項

- `design/memo` の中身（API キー等のシークレット）を出力・ログ表示・コミットしない
- 既存の商品ページを確認なしに削除しない
- 指示のないファイルの一括リネーム・移動
