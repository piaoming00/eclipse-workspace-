# 商品名クーポン表記 差し替え手順

商品名の先頭にある `【11/18！クーポンで3,648円, 40%OFF】` を、
単価表の値（日付・単価・OFF率）に差し替える。

```
変更前: 【11/18！クーポンで3,648円, 40%OFF】ワンピース リネン ...
変更後: 【11/21！クーポンで3,645円, 40%OFF】ワンピース リネン ...
```

スクリプト: `script/edit-item-name-coupon.py`

---

## 1. 入力ファイル

| ファイル | 役割 |
|---|---|
| `items/item_name/normal-item.csv` | 編集対象（RMSの商品CSV・cp932・14列・5,209行） |
| `items/02.AKI単価設定.xlsx`（シート `価格表`） | 差し替え値の参照元 |

参照するセル・列

| 項目 | 参照先 | 例 |
|---|---|---|
| 日付 | **F2** | `11/21`（日付セルでも文字列でも可） |
| 単価 | **M列**（40%OFF後価格） | `3,645` |
| OFF率 | **F4** | `0.4` → `40%OFF` |

- M列の行は **B列の「主SKU」** で商品と突き合わせる
  - `a0523`（CSV）⇔ `sa0523-a` / `sa0523-b`（シート）のような表記差は自動で寄せる
    （先頭の「英字+数字」をキーにし、`a1234` は `sa1234` として扱う）
- M列が数式のまま（計算結果が未保存）でも、数式（`ROUNDDOWN(K*(1-F),0)` / `J` 版）を判定して再現します
- 入力CSVの文字コードは自動判定（cp932 / UTF-8 BOM付き・無し）

## 2. 事前準備（必須）

1. `02.AKI単価設定.xlsx` の **F2 にクーポン期限**を入力して保存する（例: `11/21`）
   - F2が空のまま実行するとエラーになります
   - 入力したくない場合は `--date 11/21` で直接指定も可
2. F4 が今回のOFF率（`0.4`）であることを確認
3. 対象CSVが最新のダウンロード版であることを確認

## 3. 差し替えルール

| ケース | 動き |
|---|---|
| `【11/18！クーポンで3,648円, 40%OFF】` | 日付・単価・OFF率をすべて差し替え |
| `【11/20！クーポンで5,050円】`（OFF表記なし） | 差し替え後 `【11/21！クーポンで◯円, 40%OFF】` |
| `【OUTLET！クーポンで5,130円】` | 差し替え後 `【11/21！クーポンで◯円, 40%OFF】` |
| `【11/20！クーポンで3,770円～】` | `～` は維持（`...円～, 40%OFF`） |
| `【】が無い商品名` | 先頭に `【日付！クーポンで単価円, 40%OFF】` を追加 |
| 単価表に商品が無い | 変更せずレポートに記録（現在: `sa7165`） |
| 1商品に複数SKU行（価格違い） | 既定は **最も低い単価**（`--multi` で変更可） |
| 商品名が255byteを超える | **cp932換算で255byteに切り詰め**（区切りスペースまで戻す） |
| `〜`（波ダッシュ）を使っている | `～` に統一 |

元の形を保ちたい場合（OFF表記が無ければ追加しない／OUTLETを残す）は
`--shape preserve --keep-outlet` を使う。


```bash

```

- 日付・OFF率・更新件数・変更例が表示される
- F2が空のときは `--date 11/21` を付ける

### Step 2. 本実行（別ファイルに出力）

```bash

```

- 出力: `items/item_name/normal-item_namefix-YYYYMMDD-HHMMSS.csv`
- レポート: `items/item_name/report-item-name-coupon-YYYYMMDD-HHMMSS.csv`
- どちらも `normal-item.csv` と同じフォルダに作成されます

### Step 3. 結果確認

- 画面の `更新 / 【】追加 / 変更なし / 255byte切詰 / 商品名の最大byte`
- レポートの `区分` 列（更新・追加・更新(切詰め)・追加(切詰め)）
- レポートの `元byte` / `新byte` / `切詰め` 列
- 単価表に無い商品（`変更なし(単価表に商品なし)`）が想定どおりか

### Step 4. 元CSVを置き換える場合

```bash
python3 script/edit-item-name-coupon.py --in-place
```

- 上書き前に `normal-item_....bak-YYYYMMDDHHMMSS.csv` を自動作成
- 戻すときは `.bak` を元の名前にコピー

### Step 5. RMSへアップロード

- `normal-item_..._namefix-....csv` をアップロード
- 数商品の商品ページで、商品名の先頭が新しい日付・単価になっているか確認

## 5. 出力ファイル

| ファイル | 内容 |
|---|---|
| `items/item_name/normal-item_namefix-<日時>.csv` | 商品名だけ差し替えたCSV（元と同一形式） |
| `items/item_name/report-item-name-coupon-<日時>.csv` | 1商品=1行の変更レポート |

レポート列：行番号 / 商品管理番号 / 商品番号 / シート行 / 旧日付・ラベル / 旧単価 / 旧OFF /
新日付 / 新単価 / 新OFF / 区分 / 元byte / 新byte / 切詰め / 商品名(変更前) / 商品名(変更後)

## 6. オプション

| オプション | 既定 | 説明 |
|---|---|---|
| `--csv` | `items/item_name/normal-item.csv` | 対象CSV |
| `--out` | `<対象CSV名>_namefix-<日時>.csv` | 出力CSV（既定は対象CSVと同じフォルダ） |
| `--report` | `report-item-name-coupon-<日時>.csv` | レポート（既定は対象CSVと同じフォルダ） |
| `--xlsx` | `items/02.AKI単価設定.xlsx` | 単価表 |
| `--sheet` | `価格表` | シート名 |
| `--date-cell` | `F2` | 日付セル |
| `--off-cell` | `F4` | OFF率セル |
| `--price-col` | `M` | 単価の列 |
| `--date` | なし | F2の代わりに日付を直接指定 |
| `--shape` | `full` | `full`=常に日付/単価/OFFの形に揃える / `preserve`=元の形を保つ |
| `--multi` | `min` | 複数SKU時の単価（`min`/`max`/`first`/`closest`） |
| `--keep-outlet` | off | `OUTLET` を日付に置き換えない |
| `--max-bytes` | `255` | 商品名の上限バイト数（cp932換算） |
| `--no-truncate` | off | 255byte超でも切り詰めない |
| `--out-encoding` | `cp932` | 出力の文字コード（`utf-8-sig` / `utf-8` も可） |
| `--in-place` | off | 元CSVを上書き（.bak作成） |
| `--dry-run` | off | 書き出しせず確認だけ |

## 7. 実行結果（F2 = 2026/11/20 のとき）

| 項目 | 件数 |
|---|---|
| 商品名あり | 422行（1商品1行） |
| 更新 | 415（うち255byte切詰め 53） |
| 【】追加 | 7（うち255byte切詰め 2） |
| 商品名の最大byte | **255**（255byteちょうど55件） |

- 商品名の列だけが変わります（説明文などの列は変更しません）
- 255byteを超える商品名は、単語の区切り（半角/全角スペース）まで戻して切り詰め
- `〜` は `～` に統一、`‾`（U+203E）は `～` に置換（cp932に無い文字のため）

## 8. 注意

- **CSVをExcelで開いて保存しない**（クォートや改行が変わり、RMSで崩れる原因）。
  編集は必ずこのスクリプト経由で行う
- 出力形式は RMS 用（cp932 / CRLF / 1行目のみ最小クォート・データ行は全項目クォート）。
  入力がUTF-8でも自動判定して読み込みます。文字コード変換に伴い `〜`→`～` の表記統一のみ発生します
- 商品名以外の列の値は変更しません（上記の表記統一を除く）
- 単価表の行が無い商品は変更しません（レポートに残るので手動対応）
- 複数SKUで価格が違う商品は既定で最安値を表示（`--multi max/first/closest` で変更可）
- 単価表を更新したら、必ず `--dry-run` で件数を確認してから本実行する

## 9. トラブルシューティング

| 症状 | 対処 |
|---|---|
| `[ERROR] F2 が空です` | F2に日付を入力、または `--date 11/21` |
| `[ERROR] クーポン表記を解釈できません` | その行の商品名が想定外の形。表示された行番号を確認 |
| `[WARN] 単価が空の行` | 価格表のM列（またはJ列・C/D列）が空。該当行を確認 |
| `[NG] 商品名以外の列が変わっています` | スクリプトの不具合。出力せず元ファイルを確認 |
| 一部商品が更新されない | 単価表の主SKUとCSVの商品管理番号が対応していない。レポートの「単価表に商品なし」を確認 |
| OUTLET表記を残したい | `--keep-outlet`（OFF表記も元どおりにするなら `--shape preserve`） |
| 255byteで切られた名前を直したい | 元の商品名自体を短くするか、`--max-bytes` を変更（RMSは255byte制限） |
| `〜` が `～` に変わった | cp932の仕様（同じ見た目の文字）。問題ありません |
